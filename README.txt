JARVIS — Prototype iPhone 0.1

Contenu : interface web, réponses de démonstration, lecture vocale si le navigateur iOS la prend en charge, et cache hors ligne de base.

Cette version n'est PAS un assistant IA complet et ne contrôle pas les autres applications. Les intégrations PRONOTE, Deezer, téléphone, Snapchat et Instagram ne sont pas activées.

Déploiement prévu : dépôt GitHub public puis GitHub Pages.
Ne placez jamais de mot de passe, clé API ou donnée privée dans un dépôt public.
